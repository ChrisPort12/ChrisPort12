## 🌟 Proyectos destacados

### 🏔️ Rutta · E-commerce de aventura

Proyecto integrador enfocado en crear una experiencia de compra para amantes del senderismo y las actividades al aire libre.

- Investigación de usuarios, necesidades y propuesta de valor.
- Definición de alcance, requerimientos e historias de usuario.
- Catálogo con categorías, buscador, filtros, favoritos y tarjetas de producto.
- Modal de detalles, carrito funcional e interfaz adaptable a distintos dispositivos.
- Planeación de autenticación, inventario y pedidos.
- Frontend desarrollado con **HTML, CSS, JavaScript, DOM y Bootstrap**.
- Arquitectura backend proyectada con **Java, Spring Boot y SQL**.
